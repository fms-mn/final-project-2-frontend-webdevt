These local MP4 files let the frontend preview work without the FILME API or an external video host. They are sample footage, not trailers for the fictional demo movies, and the hero labels them “Demo preview video.”

- `flower.mp4`: [MDN CC0 example video](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4).
- `bunny-trailer.mp4`: [Big Buck Bunny trailer hosted by W3C](https://media.w3.org/2010/05/bunny/trailer.mp4), © Blender Foundation, licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
- `sintel-trailer.mp4`: [Sintel trailer hosted by W3C](https://media.w3.org/2010/05/sintel/trailer.mp4), © Blender Foundation, licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

The mapping to demo movie IDs lives in `client/src/data/demoHeroMedia.js`. Live movie data continues to use its own trailer URL.
